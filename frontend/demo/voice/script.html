The voice-over script

Thirteen lines, one audio file each. Copy a line, paste it into ElevenLabs, generate, and download it with the file name shown. Save the files in frontend/demo/voice/. The film will be retimed to your audio.

VoiceWarm, calm narrator, same voice for every line
ModelEleven Multilingual v2 (or v3)
SettingsStability 50% · Similarity 75% · Style 0–15%
DownloadMP3, 44.1 kHz, 128 kbps or better

Tick a line when its file is saved; the ticks stay on this computer. "Copy all" is for listening to the whole script once; the film needs the separate files.
